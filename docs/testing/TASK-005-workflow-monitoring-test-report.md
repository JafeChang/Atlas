## 🏗️ 技术架构

### 工作流引擎

```
Workflow (工作流)
  ├── TaskNode (任务节点)
  │   ├── task_id (任务ID)
  │   ├── task_func (任务函数)
  │   ├── depends_on (依赖列表)
  │   └── params (任务参数)
  ├── validate() (验证)
  ├── _topological_sort() (拓扑排序)
  └── build_celery_dag() (构建Celery DAG)
```

**特性**:
- 轻量级DAG实现
- 基于Celery Canvas（chain/group/chord）
- 自动拓扑排序
- 循环依赖检测
- 任务依赖管理

### 监控系统

```
Monitoring API (监控API)
  ├── Dashboard (仪表板)
  │   ├── 系统概览
  │   ├── 任务统计
  │   ├── 文档统计
  │   └── 实时状态
  ├── Workflows (工作流监控)
  │   ├── 工作流列表
  │   └── 工作流详情
  ├── Metrics (性能指标)
  │   ├── 成功率
  │   ├── 执行时间
  │   └── 处理速率
  └── Alerts (告警)
      ├── 失败任务
      └── 错误文档
```

**特性**:
- RESTful API设计
- 统一响应格式
- 认证保护
- 分页支持
- 时间范围筛选

# 创建工作流

# 验证工作流

# 执行工作流
