### 核心技术栈

**后端框架**:
- FastAPI 0.109+ (异步API)
- SQLAlchemy 2.0 (ORM)
- Celery (任务队列)
- Uvicorn (ASGI服务器)

**数据存储**:
- PostgreSQL 16 (主数据库)
- MinIO (对象存储)
- Redis (缓存/消息队列)
- SQLite (开发/FTS5)

**认证授权**:
- JWT Token认证
- RBAC权限控制
- API Key认证

**任务调度**:
- Celery Beat (定时任务)
- DAG工作流编排
- 任务重试机制

**容器化**:
- Docker Compose
- 6个服务编排
- 健康检查

## 📝 开发原则遵循

### ✅ 简单优先
- 能脚本解决，不做服务
- 能标准库解决，不引入第三方
- 轻量级DAG替代Airflow
- SQLite FTS5替代OpenSearch

### ✅ 本地优先
- 本地运行是第一优先级
- 不强绑定云厂商
- 所有配置可定制
- 数据隐私保护

### ✅ 显式优于隐式
- 配置文件管理
- 明确输入输出
- 明确数据结构

### ✅ 可迁移性
- 双后端支持（SQLite/PostgreSQL）
- 统一存储接口（FileSystem/MinIO）
- 数据导出功能
